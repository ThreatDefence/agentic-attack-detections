# ATT&CK coverage

Generated by `tools/build_attack.py` from the rules in this repository, checked against MITRE ATT&CK Enterprise 20.1 (pinned in `tools/attack-enterprise.json`). Every rule names at least one technique, and CI fails a pull request that adds a rule without one or names a technique that is not in that release.

522 rules cover 85 techniques. Open the layers in [`generated/attack/`](../generated/attack) with the [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/) (Open Existing Layer, Upload from local): one per framework and `agentic-attack-detections.json` for everything. Each release carries them as `agentic-attack-detections-attack.zip`.

A technique says what a rule sees, not everything the framework can do. Rules that find a framework's software on a host map to Obtain Capabilities: Tool (T1588.002). Indicator sweeps and address rules map to Active Scanning (T1595) for traffic in from a reported address and Application Layer Protocol (T1071) for traffic out to one.
